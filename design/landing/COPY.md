## Why you can trust what's on the shelf
We'd rather show ten projects we can stand behind than a hundred we can't. So there are a few rules.

1. **Someone here has checked it.** Before a project goes up, Hamster Hub looks at the work and the team behind it. The checklist is public, so you can read exactly what we look for.
2. **The money part is written down.** Each project says how it earns, who owns what, and whether it's raising. No digging through a pitch deck.
3. **You can watch it move.** Projects post updates as they go. If one goes quiet, we mark it as paused instead of leaving it up looking fresh.
4. **It all leads back to us.** Every project lists what Hamster Hub put in: people, money, or time. If it does well, you'll know where it came from.
